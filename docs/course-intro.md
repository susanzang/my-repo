# 《大模型与智能体》课程简介

> 青竹课堂

## 课程目标

- 理解大模型（LLM）的基本原理与能力边界
- 掌握 Prompt 设计、函数调用与 Agent 编排
- 能独立搭建一个可用的智能体应用

## 章节概览

| 章节 | 主题 |
| --- | --- |
| 01 | 大模型基础与能力边界 |
| 02 | Prompt 工程实践 |
| 03 | 工具调用（Function Calling） |
| 04 | 智能体（Agent）设计与编排 |
| 05 | 工作流与 ComfyUI 实战 |
| 06 | Vibe Coding：从想法到上线 |

## 适合人群

有基础编程能力、希望把大模型能力落地到业务中的开发者与产品经理。
